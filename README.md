# 🌱 AgriSense AI

🚀 AI-powered crop recommendation & price forecasting system for smart farming

---

## 💡 Overview

AgriSense AI is a decision-based system that helps farmers choose:

- 🌾 **Which crop to grow**
- 📈 **When to sell for maximum profit**

It combines **Machine Learning + Time Series Forecasting**  
to deliver real-world insights from soil data and mandi prices.

---

## ⚡ Features

🔹 Crop Recommendation using ML  
🔹 6-Month Price Forecasting using Prophet  
🔹 Profit-driven crop selection  
🔹 Uses real mandi + environmental data  
🔹 Clean UI with animations  

---

## 🧠 How It Works

1. User inputs:
   - NPK values
   - Temperature, humidity, rainfall
   - Soil pH
   - Market location  

2. Model predicts:
   - Best suitable crop 🌾  

3. Time-series model forecasts:
   - Future mandi prices 📈  

4. System suggests:
   - Most profitable crop + best selling window 💰

## 🛠️ Tech Stack

- **Backend:** Flask, Python  
- **ML:** Scikit-learn  
- **Forecasting:** Prophet  
- **Data:** Pandas, NumPy  
- **Frontend:** HTML, TailwindCSS, GSAP
